ScanPOS Bill App 🧾

تطبيق فوترة ونقطة بيع (POS) للمحلات التجارية الصغيرة، مبني بـ **Flutter**. يعمل بدون إنترنت، ويحفظ كل البيانات محليًا على الجهاز.

---

## ✨ المميزات

### 📦 إدارة المنتجات
- إضافة وتعديل وحذف المنتجات
- تسجيل الباركود، سعر البيع، سعر التكلفة، والمخزون
- سجل تلقائي لكل تغيير في سعر المنتج

### 📷 المسح والفوترة
- مسح الباركود بالكاميرا لإضافة المنتجات إلى الفاتورة
- سلة مشتريات مع حساب الإجمالي تلقائيًا
- منع البيع عند نفاد المخزون

### 🖨️ الإيصالات
- طباعة عبر طابعة بلوتوث/حرارية
- مشاركة الإيصال كملف PDF

### 📊 التقارير
- الإيرادات والأرباح (اليوم / أمس / هذا الشهر / الشهر الماضي)
- رسوم بيانية مصغرة لآخر 7 أيام
- أفضل المنتجات مبيعًا
- توقع الربح للأسبوع القادم

### 🏪 إعدادات المتجر
- بيانات المتجر (الاسم، العنوان، الهاتف، نص أسفل الإيصال) — تظهر جميعها على الإيصال
- الوضع الداكن (Dark Mode) مع حفظ اختيار المستخدم

---

## 🛠️ التقنيات المستخدمة

| الجانب | التقنية |
|---|---|
| الإطار | Flutter / Dart |
| إدارة الحالة | `flutter_bloc` (BLoC / Cubit) |
| قاعدة البيانات | SQLite عبر `sqflite` |
| الإعدادات | `shared_preferences` |
| التنقل | `go_router` |
| PDF والطباعة | `pdf` و `printing` |
| أخرى | `intl`, `gal`, `file_picker`, `share_plus` |

> 💡 الرسوم البيانية المصغرة مرسومة يدويًا بـ `CustomPainter` بدل `fl_chart` لتجنب تعارض الاعتماديات.

## 🏗️ هيكل المشروع

يتبع المشروع **Clean Architecture**، وكل ميزة مقسمة إلى ثلاث طبقات: `domain`، `data`، `presentation`.

```
lib/
├── config/
│   └── routes/          # app_routes.dart (go_router)
├── core/
│   ├── data/             # DatabaseHelper, AppSettings
│   ├── theme/            # AppTheme
│   ├── utils/            # AppValidators
│   ├── widgets/          # PrimaryButton, InputLabel ...
│   └── service_locator.dart
├── features/
│   ├── billing/          # الفاتورة، الماسح، الدفع
│   ├── product/          # إدارة المنتجات
│   ├── reports/          # التقارير والإحصائيات
│   ├── settings/         # الإعدادات والطابعة
│   └── shop/             # بيانات المتجر
└── main.dart
```

## 🚀 التشغيل

### المتطلبات
- Flutter SDK (النسخة المستقرة الأحدث)
- Android Studio أو VS Code
- جهاز أندرويد أو محاكي

### الخطوات

```bash
# 1. استنساخ المشروع
git clone https://github.com/<username>/<repo>.git
cd <repo>

# 2. تثبيت الاعتماديات
flutter pub get

# 3. التشغيل
flutter run
```

### بناء ملف APK

```bash
flutter build apk --release
```
