# ScanPOS-Mobile-App
ScanPOS - QR products scanner and billing application Download the lastest Android APK
ScanPOS Bill App 🧾

تطبيق فوترة ونقطة بيع (POS) للمحلات التجارية الصغيرة، مبني بـ **Flutter**. يعمل بدون إنترنت، ويحفظ كل البيانات محليًا على الجهاز.

---

## ✨ المميزات

- **إدارة المنتجات:** إضافة وتعديل وحذف المنتجات مع الباركود وسعر البيع وسعر التكلفة والمخزون.
- **مسح الباركود:** إضافة المنتجات إلى الفاتورة بمسحها بالكاميرا.
- **سلة المشتريات والدفع:** حساب الإجمالي، مع منع البيع عند نفاد المخزون.
- **طباعة الإيصالات:** طباعة عبر طابعة بلوتوث/حرارية، أو مشاركة الإيصال كملف PDF.
- **لوحة التقارير:** الإيرادات والأرباح (اليوم / أمس / هذا الشهر / الشهر الماضي)، رسوم بيانية مصغرة لآخر 7 أيام، أفضل المنتجات مبيعًا، وتوقع الربح للأسبوع القادم.
- **سجل الأسعار:** تسجيل تلقائي لكل تغيير في سعر المنتج.
- **بيانات المتجر:** الاسم والعنوان والهاتف ونص أسفل الإيصال، وتظهر كلها على الإيصال.
- **الوضع الداكن (Dark Mode):** يُحفظ اختيار المستخدم.

## 🛠️ التقنيات المستخدمة

| الجانب | التقنية |
|--------|---------|
| الإطار | Flutter / Dart |
| إدارة الحالة | `flutter_bloc` (BLoC / Cubit) |
| قاعدة البيانات | SQLite عبر `sqflite` |
| الإعدادات | `shared_preferences` |
| التنقل | `go_router` |
| PDF والطباعة | `pdf` و `printing` |
| أخرى | `intl`, `gal`, `file_picker`, `share_plus` |

> الرسوم البيانية المصغرة مرسومة يدويًا بـ `CustomPainter` بدل `fl_chart` لتجنب تعارض الاعتماديات.

## 🏗️ هيكل المشروع

يتبع المشروع **Clean Architecture**، وكل ميزة مقسمة إلى ثلاث طبقات: `domain` و `data` و `presentation`.

```
lib/
├── config/
│   └── routes/          # app_routes.dart (go_router)
├── core/
│   ├── data/            # DatabaseHelper, AppSettings
│   ├── theme/           # AppTheme
│   ├── utils/           # AppValidators
│   ├── widgets/         # PrimaryButton, InputLabel ...
│   └── service_locator.dart
├── features/
│   ├── billing/         # الفاتورة، الماسح، الدفع
│   ├── product/         # إدارة المنتجات
│   ├── reports/         # التقارير والإحصائيات
│   ├── settings/        # الإعدادات والطابعة
│   └── shop/            # بيانات المتجر
└── main.dart
```

## 🚀 التشغيل

**المتطلبات**

- Flutter SDK (النسخة المستقرة الأحدث)
- Android Studio أو VS Code
- جهاز أندرويد أو محاكي

**الخطوات**

```bash
# 1. استنساخ المشروع
git clone https://github.com/<username>/<repo>.git
cd <repo>

# 2. تثبيت الاعتماديات
flutter pub get

# 3. التشغيل
flutter run
```

**بناء ملف APK**

```bash
flutter build apk --release
```
